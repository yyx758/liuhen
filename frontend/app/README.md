# 留痕前端

以 `../reference/index.html` 为主要视觉原型，并参考新增的“留痕”页面设计，使用 Vue 3、TypeScript、Vite 和 Vue Router 实现首页、对话、日历、待办、资料库和留痕页面。沿用原型 CSS，并按原型结构还原页面和待办弹窗。资料库中的三篇笔记是原型示例，后端尚无文档 API；新建和打开笔记会提示暂不可用。当前共享状态较少，使用 `src/state.ts` 的 Vue 响应式对象，没有引入 Pinia。

## 本地运行

先在仓库根目录启动 FastAPI：

```powershell
python -m backend.app.main
```

另开终端：

```powershell
cd frontend/app
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173/`。开发服务固定监听 IPv4 地址 `127.0.0.1` 和端口 `5173`；修改 Vite 配置后需停止旧进程并重新运行 `npm run dev`。Vite 在开发环境将 `/tasks`、`/chat`、`/actions`、`/audit` 代理到 `http://127.0.0.1:8000`。部署时可设置 `VITE_API_BASE_URL` 指向同源反向代理或允许跨域的 API 地址。

在 Windows 上重新执行 `npm ci` 前，先停止正在运行的本项目前端开发服务器；Vite 加载的原生模块可能使依赖清理遇到 `EPERM`。日常启动无需重复执行 `npm ci`。

## 当前交互

- `/login` 展示账号密码登录界面。密码显示切换可用；提交、注册和找回密码会明确提示尚未接入，密码不会发送给后端。保持登录选项在会话机制接入前禁用。当前页面不拦截应用路由，也不提供身份校验；部署环境仍由 Caddy Basic Auth 保护 `/app/`。
- 首页和对话把自然语言发送到 `POST /chat`。每轮生成 `request_id`；发送失败后重试会复用同一个 ID。
- 对话页将助手回复按 Markdown 渲染（段落、列表、强调、链接、代码块等）；解析时禁用原始 HTML，再清理生成的 HTML 后显示。用户消息仍按原文展示。
- 手动创建使用 `POST /tasks` 和 `Idempotency-Key`。同一表单内容重试沿用同一个键。
- 页面上的手动编辑、完成状态切换和删除直接调用任务接口，并带当前版本 `If-Match`；Agent 对话产生的修改、删除建议须由用户在对话或留痕页确认。
- 提案到期后立即从留痕页的“需要确认”筛选和对话建议中隐藏，导航计数同步更新；后端定时删除到期提案并保留审计事件。
- 启动刷新只读取任务、当前待确认提案和最近 3 条审计记录。对话页按当前会话读取相关提案，任务的 AI 来源由任务列表接口给出，不再为了这些信息下载全量审计记录。对话列表和消息展示保存在当前浏览器，会话消息也持久化在后端。侧栏删除会话会清理两处记录；后端尚无供前端读取会话列表和历史的 HTTP 接口，因此清除浏览器存储后无法恢复列表。
- 留痕页通过 `/audit/events/page?page=页码&page_size=20` 按页查询，可使用上一页、下一页、页码按钮和指定页跳转；响应提供当前页、总条数、总页数和记录 ID 上界 `anchor_id`。后续页沿用该上界，翻页期间新增记录不会挤动当前结果。失败、已取消和本周筛选在后端执行，概览数字来自 `/audit/summary`。“需要确认”从有效提案列表读取并在前端分页。展开“轨迹”时仍按需使用游标接口 `/audit/events` 读取相关审计记录；后端没有保存完整工具调用步骤，因此不显示原型中的示例步骤或平均步数。
- 后端当前只提供普通 HTTP `/chat`，尚无 SSE 接口。前端按实际响应显示完整答案。
- 原型中的任务分类、备注和子任务还没有对应的后端字段；相关位置保留原型布局，但不会把未保存的数据显示为操作成功。任务列表与日历显示真实后端数据，因此数量和原型示例不同。

运行 `npm run build` 进行 TypeScript 检查和生产构建。
