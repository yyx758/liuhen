## 已实现

- 任务管理：创建、查询、修改、删除；开始时间、时长、截止时间、优先级、状态；时间段冲突检查。
- AI 对话：Agent 直接创建任务；修改、删除只生成提案，用户在独立入口确认或取消；提案 10 分钟过期。
- 操作留痕：业务变更与审计事件同事务写入只追加的 `operation_events`。
- 前端（Vue 3）：首页、对话、待办、日历、留痕页；资料库只是原型示例。
- 多用户：
  - 业务数据按 `user_id` 隔离，覆盖服务、仓储、Agent 工具全链路。
  - 账号密码登录：Argon2id、服务端会话 + HttpOnly Cookie、强制改密、Origin 校验、登录限流。
  - 注册与管理员审核；账号停用、启用、删除；只追加的账号事件 `account_events`。
  - 管理后台 `/admin`、个人设置（邮箱、在线设备、登录记录）。
  - 每日对话上限（默认 50，管理员不限量）与用量统计。
  - 账号管理命令行 `python -m backend.app.cli`。
- 邮箱验证（本阶段，未上线）：SMTP 发信；注册必须通过邮箱验证码；个人设置里绑定、修改或验证邮箱走验证码；已验证邮箱可自助找回密码（不暴露账号是否存在），管理员重置保留为兜底。
- 部署：Docker Compose + Caddy；访问控制由应用登录负责，已去掉 Basic Auth。
- 测评：26 条场景（含 3 条跨用户隔离），程序判业务分，LLM 裁判判回复分，支持抽样人工校准。
